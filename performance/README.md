# Performance tests

## TICKET-ADV097 — 100 trade creations at concurrency 10

Start ReconX and its observability services, then run:

```bash
k6 run performance/ticket-97.mjs
```

The script logs in as `trader@db.com`, sends exactly 100 uniquely referenced
trade-creation requests through 10 virtual users, and requires every response
to be HTTP 201. Override connection or credentials when needed:

```bash
BASE_URL=http://localhost:8080/api \
RECONX_USERNAME=trader@db.com \
RECONX_PASSWORD=trader123 \
RUN_OFFSET=5000 \
k6 run performance/ticket-97.mjs
```

The console and `performance/ticket-97-results.json` record request throughput,
P95 latency, check success rate, and request failure rate. During the run,
compare throughput and P95 with the Grafana request-rate and latency panels.

`RUN_OFFSET` must be between 0 and 9900 and can be changed if a persistent
database already contains trade references generated by an earlier run.
